# Richouse

**Description:** Developed 2D top-down stealth game in Python/Pygame using an OOP architecture. Implemented Flask API for storing usernames and global ranking, with POST and GET methods. Created and handled JSON file and SQLite databases, for local and server information respectively.

**Technologies:** Python 3, Pygame, SQLite 3, Flask

**How to run:**
1. Install Python 3
2. Install Pygame using "python3 -m pip install pygame"
3. Install Flask using "python3 -m pip install flask"
4. Open a terminal and open the Server-code directoty using "cd Server-code"
5. Start the flask server locally using "python3 app.py"
6. Open a second terminal and open the Distribution-code directory using "cd Distribution-code"
7. Start the game using "python3 main.py"
